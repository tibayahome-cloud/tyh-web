# Service photos

One photo per home-based service, shown on the client Services page. Name the file after the service key and the page
uses it automatically, with no code change: `src/assets/images/services/<service key>.webp`. A service with no file here
falls back to the closest stock photo in the folder above.

## Format

- WebP, 1600 x 900 (16:9), under 250 KB each. Subject centred, because the card also crops to a wide strip on phones.
- No text, logos or captions inside the image, except the Tiba Ya Home navy polo and bag the existing photos already use.
- One clear subject that tells the service apart at a glance, even at thumbnail size.

## Style (match the existing photos in `../service-*.png`)

Warm, natural daylight in a real Kenyan home interior. Kenyan carers, nurses and patients, genuine and dignified, never
staged or clinical-cold. Professionals in a navy polo with the Tiba Ya Home mark and a navy carry bag where it fits. The
patient is relaxed and cared for. No hospital corridors, no stock-photo smiles into the camera, no identifiable real
people, no brand names on equipment.
